# 🚗 AM38 – Premium Car Rental Platform (Mauritius)

🔥 Production-ready full-stack car rental system inspired by DiscoverCars & MyCarRental.

---

## 🌍 Live Features

* 🚘 Smart car browsing & filtering
* 📅 Real-time booking system
* 💳 Stripe payment integration
* 🧾 Invoice generation
* 📊 Admin dashboard (fleet calendar, reservations)
* 🔔 Notification system

---

## 🧠 Business Logic

* Dynamic pricing (per day + extras)
* Smart fleet assignment
* Availability grouping (EDAV, CDAV, etc.)
* Booking lifecycle (Pending → Confirmed → Completed)

---

## 🛠 Tech Stack

* Frontend: React + Vite + TypeScript + Tailwind
* Backend: Node.js + Express
* Database: MySQL
* Payments: Stripe
* Deployment: Docker + Nginx + AWS

---

## 🚀 Deployment

* CI/CD via GitHub Actions
* Dockerized production build
* Hosted on AWS EC2
